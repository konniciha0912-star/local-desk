# Local Desk 2.1の検証

2026-10-07、Windows / Python 3.12 / pywebview 6.2.1 / WebView2、RTX 5060 Ti 16GB、RAM 32GBで確認。

- 上端バー: 常に手前、上端y=12、折り畳み320x68、展開460x460、通常画面980x660への切替。負座標のモニターと切断後の位置は単体テスト。
- 通常画面・上端バーのどちらから終了しても、両ビューとHTTP、ショートカットのスレッドを終了。表示モード保存、通常画面のサイズ保持を確認。
- 起動から50msで閉じる実WebView2テストを通過。WebView2自体が初期化中断をログに出すことはあるが、検証プロセスとAIポートは終了する。
- 実Bonsaiの生成中に終了し、検証専用AIポート1238が閉じることを確認。通常のAIポート1235とは分離して検証。
- 表示中の上端WebView2で180フレームを測定。requestAnimationFrame間隔の中央値3.3ms、16.7ms超0件を2回確認。約300Hz相当のコールバック間隔で、あらゆる負荷・モニターで300fpsを保証する測定ではない。画面全体の提示時刻を計測した結果でもない。
- DOMテストでストリーム1000更新中のテキストノード保持、生成中Markdown解析0回、完了後1回を確認。描画はブラウザのrequestAnimationFrameでまとめ、固定の100ms間隔を廃止。
- 接続確認、PKCE/state、誤ったstate・再利用拒否、認証情報暗号化、トークン更新、プレビューの内容固定/一回限り、外部AIの確認必須、メール送信APIを使わないことを合成アカウントで検証。
- 接続情報の暗号化ファイルが履歴バックアップに入らないことを検証。
- Chromeで連携画面とInstagram参照リンク取り込みを確認。APIで動画を取得/視聴したと誤表示しない。
- 公開YouTube oEmbedの取得成功。TikTok oEmbedは実アクセスで503だったため、未取得と明示してリンクを返す復旧動作を追加。
- 合成日本語音声から作ったMP4を実Whisperでローカル文字起こし。言語jaと文字列取得を確認。

実アカウントのGoogle同意、Gmail/Instagram/TikTokのデータ取得、外部AIの課金API呼び出しは、本人の認証設定がないため未検証です。Issue投稿・メール保存・送信・SNS投稿を実アカウントで行っていません。接続手順はCONNECTIONS.mdを参照。
