# Local Desk for VS Code

Local Deskをデスクトップから開いてから使用してください。クラウドAPIや契約は不要です。

- コードを選択して右クリック → **Local Desk: 選択したコードを説明**。
- 保存したファイルで **Local Desk: このファイルの修正を相談** → 送信範囲を確認 → 差分を確認 → すべて反映。
- **Local Desk: 最後に反映した修正を取り消す**。アプリ側の変更履歴からも取り消せます。
- **Local Desk: カーソル位置を補完（実験的）**。自動補完は設定の `localDesk.inlineCompletion` で有効にできます。

修正は信頼したローカルフォルダー内で行います。保存後に別の変更があれば反映を拒否します。補完は標準4秒で停止します。性能はモデル・入力・GPUに依存し、常に正しいコードを返す保証はありません。

通常はポート8765です。別ポートで開いた場合は `localDesk.port` を変更します。

配布VSIXはVS Codeの「拡張機能: VSIXからのインストール」で導入できます。拡張機能は説明に選択コード、修正に現在のファイル、補完にカーソル前後をこのPCのLocal Deskに渡します。
